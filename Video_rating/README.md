# Video_rating

Предсказание рейтинга тайтла (в духе IMDb) по табличным метаданным — учебная задача регрессии (Kaggle-style соревнование).

## Rating.ipynb
Датасет: метаданные тайтлов (тип, жанры, год выхода, продолжительность, режиссёр/сценарист и их данные, число голосов, промо-активность, скачивания, бюджет и др.), таргет — `averageRating`.

Подход: собственный класс предобработки признаков, использующий KNN-регрессоры как feature engineering (сглаженные оценки по отдельным признакам — длина названия, год выхода, длительность, уровень промо, возраст тайтла). Финальная модель — линейная регрессия (`LinearRegression`), предсказания сохраняются в `output.txt`.
