# StanfordCars

Классификация марки и модели автомобиля по фото — учебное задание (Kaggle-style in-class соревнование "intro-dl-2025").

## stanford-cars.ipynb
Датасет: Stanford Cars, дополнительно предобработан — каждое изображение прогоняется через YOLOv8-seg, автомобиль вырезается по маске и bounding box'у (сегментированный + детектированный датасет, фон отбрасывается).

Модели: ResNet18/50/101, EfficientNet-B0/B1/B2/B3 (сравнение архитектур).

Техники: собственная реализация Label Smoothing loss (комбинация NLL-потери и KL-дивергенции с равномерным распределением), аугментации через Albumentations.
