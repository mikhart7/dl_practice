# LLM

Учебные проекты по внутреннему устройству LLM: реализация архитектуры трансформера и техник эффективного дообучения с нуля, а также низкоуровневые GPU-кернелы.

## my_llama/
Трансформер в стиле LLaMA2, реализованный с нуля на PyTorch: RMSNorm, RoPE, SwiGLU, causal self-attention. Обучение как causal language model на небольшом срезе English Wikipedia. Отдельно реализована LoRA (без сторонних библиотек) для Q/K проекций — с сохранением и загрузкой адаптеров. Конфигурация через Hydra.

Внутри (`profile_wide_deep/`) — эксперимент по сравнению "широкой" и "глубокой" версий модели при сопоставимом числе параметров, с профилированием через PyTorch Profiler и CUDA memory snapshots.

## triton/
Написание GPU-кернелов на Triton: от базовых операций (поэлементное сложение, broadcast, умножение с ReLU, backward-проход, редукция) до реализации **SmoothQuant** — INT8 activation-aware квантования весов и активаций с собственным Triton GEMM-кернелом.
